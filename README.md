# 정신간호2 이상행동 주관식 퀴즈

정신간호2 이상행동 용어 107개를 의미형과 사례형 문제로 학습하는 정적 웹사이트입니다.

## 기능

- 의미형·사례형 혼합 출제
- 1차 오답 후 한 번 더 도전
- 두 번째 오답 시 정답과 핵심 의미 공개
- 앞글자 힌트와 오답 다시 풀기
- 학습 범위 및 문제 유형 선택
- 모바일·PC 반응형 화면
- API, 회원가입, 서버 통신 없이 브라우저에서 실행
- 학습 기록은 사용 중인 브라우저의 `localStorage`에만 저장

## 바로 사용하기

GitHub Pages: https://gn7n264b8c-png.github.io/mental-nursing-quiz/

로컬에서는 `index.html`을 열면 됩니다.

## 콘텐츠 범위

용어와 의미는 사용자가 제공한 정신간호2 이상행동 PDF 두 개의 정리본을 바탕으로 하며, 사례형 문항은 해당 의미를 실제 상황처럼 연습할 수 있도록 구성했습니다.
